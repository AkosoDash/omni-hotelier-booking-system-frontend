# 🏨 Simple Hotel Booking System

Project ini dibuat untuk memenuhi **Full-Stack Take Home Assignment**.  
Fitur utama: booking kamar hotel, authentication, dashboard admin, dan request logging.

---

## 🚀 Tech Stack
- Laravel 10 (Backend)
- React 19 (Frontend)
- MySQL (Database)
- Laravel Sanctum (Auth)
- Tailwind CSS (Styling)

---

## ⚙️ Cara Menjalankan

### Backend
```bash
cd omni-hotelier-booking-system-backend
cp .env.example .env
composer install
php artisan migrate --seed
php artisan serve
```

### Frontend 
```bash
cd omni-hotelier-booking-system-frontend
npm install
npm run start
```
